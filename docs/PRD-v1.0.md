## 1. 产品定位

### 一句话定位

**ContractMind** 是一款面向非法律专业人士的 AI 合同风险审查工具，通过上传合同即可获得结构化的风险报告。

### 解决什么问题

- 普通人看不懂合同条款的法律含义
- 不知道合同里藏了哪些坑
- 请律师太贵，不请又担心
- ChatGPT 没法结构化分析合同风险

### 为什么不用 ChatGPT

| 对比维度 | ChatGPT | ContractMind |
|---------|--------|---------------|
| 上传文件 | 不支持 PDF 直接分析 | 支持 PDF/DOCX |
| 结构化报告 | 需要自己提问 | 自动生成风险报告 |
| 风险量化 | 定性回答 | 0-100 风险评分 |
| 条款定位 | 模糊描述 | 精确到具体条款 |
| 无需 Prompt | 需要用户会提问 | 零门槛，一键分析 |

## 3. 用户旅程

### 主流程：上传 → 分析 → 报告

```
用户进入网站
     ↓
   首页 (Landing)
     ↓ 点击"上传合同"
   上传页 (Upload)
     ↓ 拖拽/选择文件
   文件处理中
     ↓ 解析文本
   AI 分析中 (Processing)
     ↓ 识别风险
   风险报告 (Report)
     ↓ 可选：保存到历史
   历史记录 (History)
```

### 详细步骤

#### Step 1：进入首页

1. 用户通过搜索引擎 / 广告 / 推荐链接进入
2. 第一眼看到核心价值主张："3分钟，看懂合同风险"
3. 看到支持的合同类型（劳动合同、服务合同、NDA）
4. 点击"上传合同"按钮进入上传页
5. 或者点击"查看示例报告"了解报告样式

#### Step 2：上传合同

1. 进入上传页
2. 可选：查看支持格式（PDF、DOCX）、大小限制（10MB）
3. 拖拽文件到上传区域，或点击选择文件
4. 文件上传后显示文件名、大小、格式图标
5. 可点击"移除"重新选择
6. 点击"开始分析"按钮

#### Step 3：等待分析

1. 显示分析进度（"正在解析合同..." → "正在分析条款..." → "正在生成报告..."）
2. 预计耗时提示（"预计 10-30 秒"）
3. 禁止关闭页面提示
4. 超时处理（超过 60 秒提示"分析超时，请稍后重试"）

#### Step 4：查看报告

1. 进入报告页
2. 第一眼看到风险评分仪表盘（大数字 + 颜色）
3. 看到风险等级标签（高风险 / 中风险 / 低风险）
4. 看到风险项统计（高风险 N 项、中风险 M 项、低风险 L 项）
5. 下拉查看风险详情列表
6. 每项风险看到：条款位置、风险说明、修改建议
7. 底部看到免责声明
8. 可选：点击"上传新合同"继续分析

#### Step 5：查看历史记录

1. 点击导航栏"历史"进入历史页
2. 看到历史报告列表（文件名、合同类型、分析时间、风险等级）
3. 可按风险等级筛选（全部 / 高风险 / 中风险 / 低风险）
4. 可按时间排序（最新 / 最旧）
5. 点击任意报告可重新查看

## 5. 风险报告设计

### 风险等级定义

| 等级 | 标签 | 颜色 | 定义 |
|------|------|------|------|
| 0-29 | 低风险 | 绿色 | 合同条款基本合理，无明显坑点 |
| 30-59 | 中风险 | 黄色 | 有条款需要注意，建议修改 |
| 60-100 | 高风险 | 红色 | 存在重大风险条款，建议不要签署或必须修改 |

### 风险评分计算

```
基础分 = 0
+ 高风险项 × 25分
+ 中风险项 × 15分
+ 低风险项 × 5分
---
总分 = min(100, 基础分)
```

### 风险标签体系

| 标签 | 严重性 | 说明 |
|------|--------|------|
| 违约金过高 | High | 违约金金额或比例明显不合理 |
| 服务期陷阱 | High | 约定不合理的长服务期 |
| 竞业限制过宽 | High | 竞业限制范围、期限、补偿不合理 |
| 知识产权归属 | High | IP条款对己方不利 |
| 付款保障缺失 | High | 付款条件模糊或保障不足 |
| 保密范围过宽 | Medium | 保密义务范围超出必要 |
| 争议解决地远 | Medium | 约定在对方所在地仲裁/诉讼 |
| 合同有效期模糊 | Low | 合同起止日期不明确 |
| 表述模糊 | Low | 条款措辞不够精确，可能产生歧义 |

## 6. 功能优先级

### P0（必须上线）

| 功能 | 说明 | 理由 |
|------|------|------|
| 上传合同 | PDF/DOCX 上传 | 核心入口 |
| 合同解析 | 提取文本内容 | AI 分析基础 |
| 合同分类 | 识别 NDA/劳动合同/服务合同 | 针对性分析 |
| 条款切分 | 将合同拆分为条款 | 精确定位风险 |

| 风险报告展示 | 可视化报告页面 | 用户交付物 |

| IP 限流 | 每 IP 每天 3 次 | 成本控制 |

## 8. MVP 边界

### 明确不做

| 功能 | 原因 |
|------|------|
| **法律问答 / Chat** | 增加复杂度，需要单独 AI 模型 |
| **律师市场** | 需要 BD、资质、合规 |
| **合同起草** | 需要大量模板和法律知识库 |
| **多语言支持** | 翻译准确度难以保证 |
| **企业版 / 团队功能** | 超出 MVP 验证范围 |
| **移动端 App** | 开发成本高，先 Web 验证 |
| **支付系统** | 不是 MVP 目标 |
| **RAG 检索** | 需要向量数据库和知识库 |
| **OCR 扫描件识别** | 准确率低，用户体验差 |
| **PDF 下载** | 可后续加 |
| **邮件通知** | 可后续加 |

### MVP 成功标准

**唯一标准**：用户是否愿意上传真实合同并查看风险报告。

- 如果用户愿意 → 继续投入
- 如果用户不愿意 → 找到原因并迭代
- 不需要等其他功能才能验证这个核心假设
